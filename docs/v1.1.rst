Introduction
------------

This project provides a function to expand a path.

Installation
------------

To install ``expandpath``, you can use ``pip``.
Open your terminal and run:

.. code-block:: shell

    pip install expandpath

Typing
------

The typing conforms strictly to ``mypy``.

.. container:: versionadded

    **Added in version 1.1.**

Features
--------

``expandpath.expandpath(value: Any, /) -> Any``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This function expands a given path.

``expandpath.main``
~~~~~~~~~~~~~~~~~~~

This click command implements the CLI.

``expandpath.tests.test() -> unittest.TextTestResult``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This project can be tested through its ``test`` function.

.. code-block:: python

    import expandpath.tests
    expandpath.tests.test()
